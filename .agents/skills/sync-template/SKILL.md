# Sync Template

Confirm project provenance, source template, comparison baseline and permitted
repositories before inspection. Read the closer rules in both repositories,
preserve dirty state and classify upstream differences as applicable unchanged,
adapted, already present, conflicting or not applicable.

Present the impact and proposed adoption scope before consequential edits.
Apply only selected updates, adapt them to project decisions and validate the
project independently. Never treat the repositories as a monorepo or assume
that template recency overrides project intent.
